# КАНТОР — прототип 0.1

Исследовательский инструмент для оптимизационного планирования учебного расписания. Не официальный сервис РГАУ–МСХА. Данные демонстрационные, не отражают действительные расписания или аудитории.

## Запуск
Скачайте файл index.html и откройте в современном браузере. Установка, сервер и интернет не нужны. Для GitHub Pages включите Settings → Pages → Deploy from a branch → main / (root). Репозиторий КАНТОР отдельный от экономического мониторинга.

## Эксперимент
Откройте «Оптимизация», оставьте исходные веса, 4500 итераций и seed 2026. На демонстрационном наборе при проверке алгоритма получено 72/72 назначений, 0 нарушений реализованных ограничений, F=735.68 → 93.32. Это не доказательство глобальной оптимальности и не оценка фактической эффективности академии. Поиск эвристический. Проверка выполнена в JavaScript-среде; полноценное браузерное и нагрузочное тестирование ещё требуется.

## Данные
Импорт JSON по шаблону в интерфейсе; локальная обработка. Экспорт расписания CSV, протокола эксперимента JSON и сравнительного графика SVG. Для реального исследования требуются учебные планы, группы, преподавательская доступность, аудитории с оснащением, действующие ограничения и матрица времени переходов. Не публикуйте персональные данные в открытом репозитории. Временная сетка пока фиксированная, двухнедельная.

Проверены отказы при неизвестном маршруте, внешнем конфликте помещения и неполном охвате. Это тест JS-среды, не полноценная проверка в браузере и не фактический результат института. ## Версия 0.5 — точный решатель и качество данных

- **Только ИЭУ АПК.** Официальный реестр расписаний проверен по доступной странице https://rgau-msha.ru/students/raspisanie и https://rgau-msha.ru/about/sveden/document/rezhim-zaniatii-obuchaiushchikhsia. Прямые PDF при повторной загрузке оказались недоступны; новых записей из них не добавлено. Действующие замены следует сверять в https://eg.timacad.ru/schedule/groups/.
- Контроль первичных записей: 305 ячеек двух страниц, из них 108 с простой структурой, 97 с потенциальным совпадением потока, 100 требуют ручного разбора. 134 предварительных кандидата не являются подтверждёнными занятиями; автоматического допуска в оптимизатор нет. Экспорт пакета сверки CSV/JSON с ID и ссылками на источник.
- CP-SAT: `solver/cp_sat.py`, `solver/requirements.txt`, `solver/test_cp_sat.py`. Локальный запуск (данные остаются у исследователя): `pip install -r solver/requirements.txt`, затем `python solver/cp_sat.py input.json output.json --seconds 120`. Входной формат — JSON из вкладки «Единое ядро», фиксированные аудитории и двухнедельный горизонт. Точное кодирование последовательных переходов, пропуск неизвестных маршрутов запрещён, учёт известных внешних назначений, 8 целочисленных критериев. В отличие от эвристики, включает внешние назначения в окна и нагрузку активного дня; минуты округляются вверх. Целевые функции двух решателей не следует сопоставлять без унификации.
- CP-SAT сообщает OPTIMAL / FEASIBLE / INFEASIBLE / UNKNOWN, целевую функцию, нижнюю границу и относительный разрыв при наличии решения. Отдельная проверка в Python пересчитывает критерии и жёсткие ограничения; вкладка «CP-SAT · точный расчёт» дополнительно проверяет импортированный протокол в браузере. Проверка протокола не доказывает нижнюю границу самостоятельно.
- Автоматические тесты на GitHub Actions (синтетические примеры): оптимум сравнивается с полным перебором, проверяются неизвестный маршрут, внешнее пересечение, неполный охват и потеря занятия. Первый запуск успешно завершён: https://github.com/Strelkov23/kantor/actions/runs/45399601873. Добавлен отдельный тест пилота с условными маршрутами.
- Полная оцифровка, достоверная матрица пеших маршрутов, вместимость и доступность ресурсов не завершены. Рабочее расписание всего института не получено. Не публиковать непубличные данные преподавателей/студентов в открытом репозитории.
