Экспорт пакета сверки CSV/JSON с ID и ссылками на источник.
- CP-SAT: `solver/cp_sat.py`, `solver/requirements.txt`, `solver/test_cp_sat.py`. Локальный запуск (данные остаются у исследователя): `pip install -r solver/requirements.txt`, затем `python solver/cp_sat.py input.json output.json --seconds 120`. Входной формат — JSON из вкладки «Единое ядро», фиксированные аудитории и двухнедельный горизонт. Точное кодирование последовательных переходов, пропуск неизвестных маршрутов запрещён, учёт известных внешних назначений, 8 целочисленных критериев. В отличие от эвристики, включает внешние назначения в окна и нагрузку активного дня; минуты округляются вверх. Целевые функции двух решателей не следует сопоставлять без унификации.
- CP-SAT сообщает OPTIMAL / FEASIBLE / INFEASIBLE / UNKNOWN, целевую функцию, нижнюю границу и относительный разрыв при наличии решения. Отдельная проверка в Python пересчитывает критерии и жёсткие ограничения; вкладка «CP-SAT · точный расчёт» дополнительно проверяет импортированный протокол в браузере. Проверка протокола не доказывает нижнюю границу самостоятельно.
- Автоматические тесты на GitHub Actions (синтетические примеры): оптимум сравнивается с полным перебором, проверяются неизвестный маршрут, внешнее пересечение, неполный охват и потеря занятия. Первый запуск успешно завершён: https://github.com/Strelkov23/kantor/actions/runs/45399601873. Добавлен отдельный тест пилота с условными маршрутами.
- Полная оцифровка, достоверная матрица пеших маршрутов, вместимость и доступность ресурсов не завершены. Рабочее расписание всего института не получено. Не публиковать непубличные данные преподавателей/студентов в открытом репозитории.
