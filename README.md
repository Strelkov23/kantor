# КАНТОР — прототип 0.1

Исследовательский инструмент для оптимизационного планирования учебного расписания. Не официальный сервис РГАУ–МСХА. Данные демонстрационные, не отражают действительные расписания или аудитории.

## Запуск
Скачайте файл index.html и откройте в современном браузере. Установка, сервер и интернет не нужны. Для GitHub Pages включите Settings → Pages → Deploy from a branch → main / (root). Репозиторий КАНТОР отдельный от экономического мониторинга.

## Эксперимент
Откройте «Оптимизация», оставьте исходные веса, 4500 итераций и seed 2026. На демонстрационном наборе при проверке алгоритма получено 72/72 назначений, 0 нарушений реализованных ограничений, F=735.68 → 93.32. Это не доказательство глобальной оптимальности и не оценка фактической эффективности академии. Поиск эвристический. Проверка выполнена в JavaScript-среде; полноценное браузерное и нагрузочное тестирование ещё требуется.

## Данные
Импорт JSON по шаблону в интерфейсе; локальная обработка. Экспорт расписания CSV, протокола эксперимента JSON и сравнительного графика SVG. Для реального исследования требуются учебные планы, группы, преподавательская доступность, аудитории с оснащением, действующие ограничения и матрица времени переходов. Не публикуйте персональные данные в открытом репозитории. Временная сетка пока фиксированная, двухнедельная.

## Версия 0.3 — многокритериальная модель и сверка исходников
- 18 критериев, 7 весовых профилей, таблица формул и весов, независимая программная проверка сохранения назначений, пересечений, дневных лимитов и переходов; Парето-анализ только среди найденных вариантов. Сохранение исходного порядка лекций и практик по умолчанию (прокси-критерий, не педагогическая сертификация).
- Настраиваемые дневные лимиты, фиксация дня, число итераций и seed. CSV сравнения и JSON протокола эксперимента.
- Первичная ручная транскрипция первой страницы расписания 1 курса: 5 групп, 148 непустых ячеек «группа × интервал × половина». Не уникальные занятия; не допущены к оптимизации до повторной сверки потоков/подгрупп. Официальный реестр повторно открыт 24.11.2026.
- Тест 7 сценариев с seed 2026, 2500 итераций, условными 5 минутами между корпусами и 5 минутами запаса, лимитами 5 пар: 41/41 назначений, 0 внутренних нарушений, 0 новых инверсий лекция–практика. Сбалансированный: окна групп 2→0, преподавателей 6→1, путь групп 195→115, преподавателей 90→50, 33 переноса. Пространственный: путь групп 195→70, преподавателей 90→20, 36 переносов. Минимум изменений: 10 переносов, окна групп 2→0, преподавателей 6→3. Некоторые показатели ухудшаются; результаты не являются доказательством глобального оптимума или эффективности реального внедрения.
- Проверка алгоритма выполнена в JS-среде, а не в полноценном браузере. Ограничения внешней занятости, маршрутов, вместимости, календаря и доступности ещё не обеспечены; расписание всего института не оптимизировано.
